# Contribuir

1. Abra un issue con objetivo, prerrequisitos y criterio cuantitativo.
2. Acuerde la formulación antes de implementar un ejemplo extenso.
3. Cree una rama `feat/...`, `fix/...`, `docs/...` o `chore/...`.
4. Añada código, metadata, prueba y página de aprendizaje en el mismo cambio.
5. Ejecute `ruff check .`, `pytest` y `mkdocs build --strict`.
6. Abra un pull request con Conventional Commits y solicite revisión técnica y de contenidos.

Una simulación no se acepta solo porque termina: debe verificar convergencia
del solver y una solución, tasa, balance o invariante. Las contribuciones
inspiradas en ALL-FEM deben incluir una ficha de independencia y no copiar
código o activos cuya licencia no esté declarada.
