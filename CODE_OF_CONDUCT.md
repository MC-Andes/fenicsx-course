# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Las interacciones deben ser respetuosas, inclusivas y centradas en la calidad
del aprendizaje. Reporte incidentes de forma privada a los mantenedores de
MC-Andes mediante los canales publicados por la organización.
