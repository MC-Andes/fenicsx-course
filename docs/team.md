## Cómo se reconoce una contribución

- Los commits y pull requests conservan la autoría técnica.
- `CITATION.cff` identifica autores y mantenedores de cada release estable.
- Una contribución sustancial puede añadirse a esta página con consentimiento.
- No se publican correos, fotografías ni otros datos personales sin
  confirmación.

## Identidad visual

La paleta editorial —papel cálido, tinta oscura, verde profundo y acento
terracota— y la combinación tipográfica serif/sans toman como referencia el
[Dossier de Diego Uribe-Suárez](https://github.com/duribes/Dossier). La
implementación para MkDocs es original y mantiene los componentes de navegación,
código y accesibilidad de Material for MkDocs.
