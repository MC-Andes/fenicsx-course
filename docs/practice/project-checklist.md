# Lista personal para un proyecto integrador

No es una rúbrica y no asigna puntajes. Marca cada casilla para descubrir qué
parte de tu simulación todavía necesita trabajo.

## Modelo

- [ ] Puedo explicar fenómeno, dominio, parámetros y unidades.
- [ ] Escribí forma fuerte, condiciones y estado inicial cuando aplica.
- [ ] Derivé cada término de la forma débil y revisé signos.

## Discretización

- [ ] Justifiqué malla, etiquetas, elementos y grados.
- [ ] Comprobé medidas/grupos físicos antes de resolver.
- [ ] Las restricciones eliminan nullspaces o los trato explícitamente.

## Solución y verificación

- [ ] PETSc informa convergencia positiva y conservo sus iteraciones/razón.
- [ ] Tengo una solución, tasa, balance o invariante independiente.
- [ ] Justifiqué tolerancias y probé sensibilidad de malla/tiempo pertinente.
- [ ] Serial y MPI representativo coinciden dentro de tolerancia.

## Reproducción

- [ ] Un script `.py` canónico parte de un checkout limpio.
- [ ] Guardé comando, versiones y resumen JSON.
- [ ] Cité fuentes y revisé licencias de activos/código.
- [ ] La visualización incluye unidades, escala y descripción textual.

Si una casilla queda vacía, vuelve al módulo relacionado o consulta la solución
después de intentar una explicación propia.
