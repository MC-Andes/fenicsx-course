# Ejercicios y soluciones

Los ejercicios son scripts `.py`; no requieren cuadernos Jupyter. Cada archivo
de inicio contiene una tarea acotada y la carpeta `solutions/` ofrece una ruta
posible después de intentar el problema.

## Método de trabajo

1. Lee la consigna y escribe una predicción.
2. Ejecuta el archivo inicial para entender la salida esperada.
3. Completa o modifica el script sin abrir la solución.
4. Comprueba unidades, signo y tolerancia.
5. Compara con la solución y explica cualquier diferencia.

Las soluciones no son plantillas para copiar. Si tu implementación usa otra
ruta y satisface la misma evidencia física o numérica, también es válida.

## Proyecto libre

Después de una ruta física, adapta un ejemplo canónico a un problema propio y
usa la [lista de proyecto](project-checklist.md) para revisar formulación,
discretización, solver, verificación y reproducción.
