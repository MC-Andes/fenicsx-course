# Accesibilidad y estilo del material

- El español es claro y el término inglés aparece en la primera mención útil.
- Las figuras requieren texto alternativo y descripción del resultado.
- Se usan paletas perceptualmente uniformes y el color nunca es el único canal.
- Cada ecuación tiene una explicación textual y sus unidades se declaran.
- Los comandos son copiables; los bloques extensos enlazan el script canónico.
- Tiempo, costo y modo `--quick` se informan antes de ejecutar.
- La navegación muestra nivel y prerrequisitos; el glosario conecta símbolos y API.
- La interfaz respeta `prefers-reduced-motion` y conserva fuentes de respaldo si
  las tipografías web no están disponibles.

La paleta actual supera contraste WCAG AA: tinta/marfil 16.54:1,
verde/marfil 7.44:1, terracota/marfil 7.27:1 y blanco/verde 7.82:1.

Una revisión editorial debe probar zoom al 200 %, navegación por teclado,
contraste y lectura sin figuras antes de cada release estable.
