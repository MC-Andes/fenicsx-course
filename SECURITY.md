# Seguridad

No publique vulnerabilidades ni credenciales en un issue. Use el reporte
privado de seguridad de GitHub. El proyecto no ejecuta código de usuarios no
confiable y los artefactos didácticos no deben contener secretos ni datos
sensibles. Se mantienen las versiones `v1.x`; las versiones `0.x` reciben
correcciones de mejor esfuerzo hasta la primera versión estable.
